# Continuous security checks

CodeQL analyzes the public JavaScript/TypeScript repository on pull requests, main pushes and weekly. It uses no application secrets or deployments. GitHub Actions are pinned to verified commit SHAs and repository permissions are read-only except the analysis job's security-events write permission. Dependabot checks npm and Actions monthly with limited open pull requests and grouped non-major development updates; nothing auto-merges. Enable dependency-graph/security alerts and require reviewed checks in repository settings separately. Secret scanning/push protection must be verified in settings; this file does not claim they are active. CodeQL results must be reviewed after the first GitHub run; YAML validation alone is not an analysis result.
